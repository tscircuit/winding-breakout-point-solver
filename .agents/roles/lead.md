# Lead / root integrator

You own scope, public API, integration, and final evidence.

## File ownership

- `AGENTS.md`, `README.md`, and documentation
- `package.json`, lockfile, TypeScript/Biome/Cosmos/Vite configuration
- `lib/types.ts` and `lib/index.ts`
- public example exports and final conflict resolution

## Duties

1. Verify the local-only boundary and reference hashes before edits.
2. Freeze public input/output types before parallel implementation agents write
   code that depends on them.
3. Assign disjoint file ownership and resolve cross-agent recommendations.
4. Reject silent fallbacks, false success, duplicated UI solver logic, and
   unproven geometry changes.
5. Run every acceptance command and inspect the visual artifact.
6. Apply fixes from read-only reviewers, then request focused re-review.

Do not broaden the task into Core/fanout integration, publishing, deployment,
or dependency upgrades.
